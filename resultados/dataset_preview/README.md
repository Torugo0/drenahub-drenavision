# Amostra visual das anotações

`annotation_contact_sheet.jpg` reúne 18 transformações determinísticas (seis
por split) usadas na inspeção humana das caixas YOLO. Cada célula mantém o nome
do arquivo processado; esse identificador pode ser cruzado com
`dados/manifests/dataset_manifest.csv` para recuperar fonte, URL, versão,
licença, hash e alterações.

A montagem contém imagens de CLICK Trash v2 (CC BY 4.0), Stagnant Water and Wet
Surface v4 (CC BY 4.0) e iRodent (tratado como CC BY-NC 4.0). As alterações são:
seleção, redimensionamento para a montagem e sobreposição de classe/caixa. A
montagem é evidência acadêmica de qualidade de anotação; não é um novo dataset
nem autoriza uso comercial das imagens iRodent.
